# dsh-board（任务面板）

把 `Deviel\03-待办\_现在.md` 读成一块能看的板子：谁在做、谁卡住、谁超期、谁没活。只读——它不改你的源文件，只读它、画它。

## 三个核心

1. **一个数据源**：`_现在.md`。脚本 `build-board.mjs` 解析成 `_state.json`，面板只吃这份状态，不自己猜。
2. **三档判据分开**：「在做 / 卡住 / 超期 / 判不出」各有各的来路——卡住只认行里明写的 `卡住：原因`，超期只认 `｜期:A→B` 里 B 早于今天，判不出是"算不出时间"而不是"很久没动"。**不拿文件修改时间当证据**（那是最早一版最大的假警报来源）。
3. **每行能追回原处**：点一行能看到它来自哪个文件的哪一行，改的时候知道去哪儿改。

## 安全阀

- 只读：没有写 `_现在.md` 的路径。所有接口都是 GET（`/board/api/data`、`/board/api/export`…）。
- 出错不白屏：面板有错误边界，崩溃会把原因写到 `~/.dsh/dsh-board-last-error.txt`，界面只显示一句人话。
- 自描述：`/board/api/about` 返回版本和数据源，`/board/api/status` 返回这张板子自己健不健康。

## 装

```bash
# 1) 放进同一个仓库根（或你自己的目录），在 profile 的 package.json 里加依赖
"dsh-board": "link:D:/AI/DeepSeek/dsh-board"

# 2) 在 dsh.profile.bundles 里加一项
"dsh-board"

# 3) 确认 patch 存在（插件名必须与包名一致）
dsh-board/cordis.patch.yml → insert: id/name: dsh-board, inject: [webServer]
```

## 重启一次 DSH（bundle 层要重启才组装）

重启后打开：设置 → **任务板**（`settings.section`，id 为 `board`）。

## 1.0 有什么

- 从 `_现在.md` 生成的板子：**在做 / 卡住 / 超期 / 判不出 / 没活** 五档，表头一行说清各自几条。
- 每个大任务可展开到步骤，能看到 `｜人:`、`｜期:`、`｜验:`、`｜已验:`、`｜算过:`、`｜授权:` 各栏。
- 阶段颜色条、人名不换行、行距压缩到一屏能多看几条。
- 点一行看来源文件与行号；`/board/api/export` 出一份纯 HTML 版（给别人看用）。
- 错误边界 + 自查接口（`/board/api/status`、`/board/api/about`）。

## 已知没做的

- **两套渲染还没统一**：面板（`client.js`）和导出页（`/board/api/export`，服务端拼 HTML）是两套代码，样式会漂。**导出页不是面板的像素复刻**，别拿它当"面板长这样"的证据。
- 只读：不能在面板上直接改状态、不能派活、不能关任务。
- 时间判据依赖行里写的日期；没有日期就落进"判不出"，不会兜底猜。
- 没有移动端专门布局（手机能看，但只是宽度挤进去）。
- 做梦/记忆那两块的趋势图没接进来。
